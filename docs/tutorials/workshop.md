# Workshop Guide

A ready-to-run session for a class, reading group or internal training day. Every command is offline and uses synthetic fixtures.

## Formats

| Format | Time | Programme |
|---|---|---|
| Taster | 60 min | Demo 01, Demo 07, discussion |
| Half day | 3 h | Beginner tier + Demo 04 + claim-ledger exercise |
| Full day | 6 h | Beginner, standard and one extension track, closing presentations |

## Facilitator notes

- Run `make verify-safety` before the session and again at the end.
- Pair participants; one runs the commands, the other records the claim and its limit.
- Keep the venue map open in a second tab: [Venue Map](../venues.md).
- Do not present any toy result as evidence about a real system, dataset or population.
